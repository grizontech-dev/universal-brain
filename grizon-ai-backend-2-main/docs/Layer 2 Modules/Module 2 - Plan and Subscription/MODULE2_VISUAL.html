Cancel: Graceful vs Immediate

flowchart TD start([POST /subscription/cancel]) --> chk{immediate?} chk -- no --> g1[UPDATE active SET cancel_at_period_end=true] g1 --> g2[INSERT history 'cancel_scheduled'] g2 --> g3[emit subscription.cancel_scheduled] g3 --> g4[200 OK { effectiveAt: currentPeriodEnd }] g4 -.-> cron[(renewal cron, future)] cron --> c1[UPDATE old status='cancelled'] c1 --> c2[assignFreePlan] c2 --> c3[emit subscription.cancelled + subscription.created] chk -- yes --> i1[BEGIN tx] i1 --> i2[UPDATE old status='cancelled'] i2 --> i3[INSERT history 'cancelled' mode=immediate] i3 --> i4[INSERT FREE sub status='active'] i4 --> i5[INSERT history 'created' reason='immediate_cancel'] i5 --> i6[COMMIT] i6 --> i7[emit subscription.cancelled + subscription.created] i7 --> i8[200 OK { subscription:<FREE>, cancelledSubscriptionId }]

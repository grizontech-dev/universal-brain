Three-Layer Cache — stacked savings, ~60–80% cost reduction
Layer 1 — Semantic Response
Qdrant + Redis · cross-user
~31%
of queries hit before any LLM call. Embed query → cosine ≥ 0.92 → return cached answer.
Layer 2 — Provider Prompt
Anthropic · OpenAI · Google
70–90%
off cached input tokens for repeat calls. Anthropic explicit (cache_control), OpenAI auto, keepalive every 4min.
Layer 3 — Model Tier Routing
router/modelSelector
60–80%
on model spend. Simple → Haiku/Mini · Complex → Opus/GPT-4. Cheapest model that can answer correctly.

Memory — three tiers, different lifespans
Tier 1 — In-Context
RAM
Lifespan: one request
Last 10–20 messages sent raw to LLM. Always present. No store.
Tier 2 — Session
Redis
Lifespan: 24h idle TTL
Full conversation cache + rolling summary. Hydrates fast on conversation reopen.
Tier 3 — Long-Term
Qdrant per user
Lifespan: permanent
Extracted facts. Recalled by similarity. User-controllable via /api/v1/memory.

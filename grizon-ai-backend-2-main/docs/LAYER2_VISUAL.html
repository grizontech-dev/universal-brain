Credit Wallet — How Costs Are Calculated
FORMULA
credits = ceil( (input_tokens + output_tokens) × model_rate × agent_multiplier × plan_discount )
All three multipliers are stored in the database and editable from the Admin Panel — no code changes needed to reprice.

Feature Usage Limits — Quotas on Expensive External Features
Feature limits are separate from global rate limits. They count only calls to specific expensive features (web search, code execution) and are tracked per-user with Redis INCR counters. When exceeded, the request returns 429 FEATURE_LIMIT_EXCEEDED with reset time and upgrade URL.

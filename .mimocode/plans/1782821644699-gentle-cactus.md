# Plan: Supabase Connector Prompt in Brain Sidebar

## Goal
When a Brain project finishes building, show a prompt in the left sidebar asking the user to connect Supabase. Three options: connect via OAuth, paste credentials manually, or skip and download the project.

## What Exists Already
- **Backend OAuth flow**: `/connect-supabase/login`, `/connect-supabase/status`, `/connect-supabase/oauth2/callback` — all working
- **Connector model**: Shared `Connector` table with `type="supabase"`, stores encrypted tokens in `config` JSON
- **Supabase template**: `backend/supabase/client.js` reads `process.env.SUPABASE_URL` and `SUPABASE_ANON_KEY` — but no .env file is generated
- **No "Connect Supabase" prompt** exists anywhere in Brain sidebar
- **Build completion**: All paths converge in `completeRunnerBuild()` at `BrainMessages.tsx:432-446`

## Implementation

### Step 1: Backend — Save manual Supabase credentials
**File**: `grizon-ai-backend-2-main/Brain/modules/connectors/supabase/controller.py`

Add a new endpoint `POST /connect-supabase/save-credentials` that accepts `{ url: string, anon_key: string }` from the frontend and saves them to the `connectors` table with `type="supabase"`, `config={url, anon_key}`. This is for users who paste credentials directly instead of using OAuth.

### Step 2: Backend — Save credentials into workspace .env
**File**: `grizon-ai-backend-2-main/Brain/modules/connectors/supabase/controller.py`

Add `POST /connect-supabase/apply-to-workspace` endpoint that accepts `{ workspace_id, url, anon_key }` and writes/updates `backend/.env` file in the workspace directory with:
```
SUPABASE_URL=<url>
SUPABASE_ANON_KEY=<anon_key>
```
Also updates `backend/supabase/client.js` if needed.

### Step 3: Frontend — Create `BrainSupabasePrompt` component
**File**: `Grizon-AI-Frontend-v2-api-2/brain/components/BrainSupabasePrompt.tsx`

A card component shown inline in the chat after build completes. Three sections:
1. **"Connect Supabase"** button → redirects to OAuth flow (`/connect-supabase/login`)
2. **"Paste Credentials"** form → two inputs (Supabase URL, Anon Key) + Save button → calls `POST /connect-supabase/save-credentials` then `POST /connect-supabase/apply-to-workspace`
3. **"Skip — Download Project"** link → triggers ZIP download so user can set up .env locally

### Step 4: Frontend — Inject prompt after build completion
**File**: `Grizon-AI-Frontend-v2-api-2/brain/components/BrainMessages.tsx`

In the `completeRunnerBuild()` function (line 432), after setting build finished, check if Supabase is already connected via `GET /connect-supabase/status`. If not connected, append a special message to the messages array:
```tsx
{
  id: `supabase-prompt-${Date.now()}`,
  role: 'agent',
  content: '',
  showSupabasePrompt: true,  // custom flag
  timestamp: new Date().toLocaleTimeString(),
}
```

### Step 5: Frontend — Render prompt in BrainAgentMessage
**File**: `Grizon-AI-Frontend-v2-api-2/brain/components/BrainAgentMessage.tsx`

When `message.showSupabasePrompt === true`, render the `BrainSupabasePrompt` component instead of (or after) the regular markdown content.

### Step 6: Backend — Inject .env into workspace on Supabase connect
**File**: `grizon-ai-backend-2-main/Brain/modules/connectors/supabase/controller.py`

After successful OAuth callback or credential save, if a `workspace_id` is provided, write the `.env` file into the workspace so the sandbox preview works with live Supabase data.
